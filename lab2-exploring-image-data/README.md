# Lab 2: Exploring Image Data

## Overview

This lab introduces image data inspection and preprocessing. It focuses on loading image folders, visualizing sample images, and preparing image arrays for later modeling workflows.

## Skills Demonstrated

- Image loading and directory traversal
- Visual inspection of image classes
- Basic image preprocessing
- Dataset shape and class balance checks

## Data

The notebook expects the Intel Image Classification dataset in a local `Data/INTEL/` directory outside this lab folder. The image dataset is not committed because of size. Keep large image data local and document the source when reproducing the analysis.

## Review Notes

This lab is best reviewed for image data handling fundamentals and preprocessing setup rather than final model performance.
