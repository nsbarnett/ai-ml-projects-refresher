# Lab 1: Exploring Table Data

## Overview

This lab explores a residential rent dataset to identify data quality issues, summarize key variables, and understand relationships between rental price and housing features.

## Skills Demonstrated

- Loading and inspecting tabular data
- Cleaning categorical and numeric fields
- Descriptive statistics and visual exploration
- Feature interpretation for rental housing data
- One-hot encoding for downstream modeling

## Data

The dataset comes from the Kaggle House Rent Prediction dataset. The zip file contains `House_Rent_Dataset.csv` and `Dataset Glossary.txt`. Extract the archive into `data/` before running the notebook from this folder.
