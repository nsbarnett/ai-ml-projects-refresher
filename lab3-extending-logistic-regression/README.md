# Lab 3: Extending Logistic Regression

## Overview

This lab extends logistic regression beyond a basic library call by comparing approaches, preparing credit-score classification data, and evaluating model behavior.

## Skills Demonstrated

- Data cleaning and feature preparation
- Logistic regression model comparison
- Optimization and convergence analysis
- Classification evaluation
- Clear notebook-based experimentation
