# Lab 5: Wide and Deep Networks

## Assignment Summary

This lab explores the concept of combining wide (linear) and deep (neural network) models to capture both memorization and generalization.

## Objective

Understand how hybrid architectures can improve model performance by leveraging both feature interactions and learned representations.

## What Was Accomplished

- Studied wide vs deep modeling approaches
- Implemented or reviewed hybrid architecture
- Evaluated performance differences between model types

## Outcomes

- Improved understanding of representation learning
- Learned when deeper models provide value over simpler approaches

## Key Takeaways

Wide and deep models balance memorization and generalization, making them useful for structured data tasks.
