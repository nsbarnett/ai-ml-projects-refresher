# Lab 4: Multi-Layer Perceptron

## Assignment Summary

This lab focuses on implementing and understanding a Multi-Layer Perceptron (MLP), a foundational neural network architecture used for supervised learning tasks.

## Objective

The goal is to build, train, and evaluate a feedforward neural network and understand how hidden layers, activation functions, and training processes impact performance.
