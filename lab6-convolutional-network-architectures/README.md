# Lab 6: Convolutional Network Architectures

## Assignment Summary

This lab focuses on convolutional neural networks (CNNs), which are widely used for image-based tasks.

## Objective

Understand how convolutional layers extract spatial features and how CNN architectures are constructed and trained.

## What Was Accomplished

- Built or analyzed CNN architectures
- Explored convolution, pooling, and activation layers
- Evaluated model performance on image data

## Outcomes

- Reinforced understanding of feature extraction in images
- Learned how CNNs differ from traditional neural networks

## Key Takeaways

CNNs are highly effective for image-based tasks due to their ability to capture spatial hierarchies in data.
