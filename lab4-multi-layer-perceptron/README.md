# Lab 4: Multi-Layer Perceptron

## Overview

This lab applies multi-layer perceptron models to census-style tabular data and compares neural network behavior across different configurations.

## Skills Demonstrated

- Tabular data preparation for neural networks
- Feature scaling and train/test workflow
- MLP architecture design
- Training, validation, and model comparison
- Interpretation of classification performance
