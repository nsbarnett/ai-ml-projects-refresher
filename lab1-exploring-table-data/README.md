# Lab 1: Exploring Table Data

## Assignment Summary

This lab focuses on exploratory analysis of a tabular dataset. The assignment centers on understanding data structure, identifying data quality issues, inspecting feature relationships, and documenting early observations that would support future modeling work.

## Objective

The goal of this assignment is to explore a structured housing rental dataset, clean and inspect the available features, and identify patterns that matter for downstream prediction tasks.

## Dataset

**Source:** [Kaggle - House Rent Prediction Dataset](https://www.kaggle.com/datasets/iamsouravbanerjee/house-rent-prediction-dataset)

The dataset includes housing rental listings and related attributes such as rent, location, furnishing status, size, room count, floor, and bathrooms.
