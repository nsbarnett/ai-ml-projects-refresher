# Lab 5: Wide and Deep Networks

## Overview

This lab builds wide and deep neural network architectures for mixed tabular features and compares model designs on credit-score classification data.

## Skills Demonstrated

- Mixed numeric and categorical feature preparation
- Wide and deep model construction
- Neural network training and validation
- Architecture visualization
- Model comparison using training history and evaluation metrics

## Contents

| Path | Purpose |
| --- | --- |
| `lab5_wide_and_deep_networks.ipynb` | Main wide and deep learning notebook |
| `data/train.csv` | Training dataset |
| `data/test.csv` | Test dataset |
| `artifacts/model.png` | Generated model architecture diagram |
