# AI/ML Projects Refresher

A curated refresher repository of seven machine learning labs completed as part of a university AI/ML course. This repo has been cleaned up to make each lab easier to navigate, review, and revisit for interview prep, skill refresh, and portfolio use.

## Repository Goals

- Revisit core machine learning and deep learning concepts
- Preserve prior coursework in a cleaner and more professional format
- Standardize documentation across assignments
- Highlight what each lab set out to do, what was completed, and what was learned

## Labs Overview

| Lab | Folder | Topic | Main Focus | Outcomes |
|---|---|---|---|---|
| 1 | `lab1-exploring-table-data` | Exploring Table Data | Exploratory analysis of structured housing rental data | Practiced data cleaning, feature inspection, summary statistics, and visual analysis |
| 2 | `lab2-exploring-image-data` | Exploring Image Data | Image preprocessing, visualization, and dimensionality reduction planning | Reviewed image dataset structure, preprocessing workflow, and exploratory analysis requirements |
| 3 | `lab3-extending-logistic-regression` | Extending Logistic Regression | Extending and comparing logistic regression approaches | Reinforced classification workflows and experimental comparison structure |
| 4 | `lab4-multi-layer-perceptron` | Multi-Layer Perceptron | Building and evaluating feedforward neural networks | Revisited neural network fundamentals, hidden layers, and model training concepts |
| 5 | `lab5-wide-and-deep-networks` | Wide and Deep Networks | Comparing shallow and deeper architectures | Strengthened understanding of representation learning and architecture tradeoffs |
| 6 | `lab6-convolutional-network-architectures` | Convolutional Network Architectures | Building convolution-based image models | Reinforced CNN building blocks, feature extraction, and architecture design |
| 7 | `lab7-recurrent-network-architectures` | Recurrent Network Architectures | Sequential modeling with recurrent networks | Revisited sequence modeling concepts and RNN-based architecture workflows |

## Standard Folder Structure

Each lab folder is documented to follow the same general pattern where applicable:

```text
lab-name/
├── README.md              # Assignment summary, accomplishments, and outcomes
├── *.ipynb / *.py         # Main notebook or implementation files
├── data/                  # Dataset notes or local data references when applicable
└── outputs/               # Saved figures or derived outputs when applicable
```

Some labs may not yet contain every subfolder above, but the documentation for each lab now follows one consistent format.
